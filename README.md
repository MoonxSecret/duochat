# DuoChat 0.2 — кроссплатформенный прототип

## Включено
- Общие комнаты по короткому коду.
- Обмен сообщениями в реальном времени через Socket.IO.
- Локальная история на каждом устройстве в IndexedDB.
- PWA-заготовка для Android Chrome и iPhone Safari.
- Серверный адаптер для совместимого Chat Completions API.
- Dockerfile для развёртывания.

## Важные ограничения (прочитайте до использования)
Это **не готовый APK или IPA**, а исходный проект для тестирования.
Сервер работает как ретранслятор: тела сообщений не сохраняются на сервере. История остаётся в браузере каждого устройства. Поэтому сообщения, отправленные, пока второй участник офлайн, ему не доставятся. Это ещё не полная двусторонняя синхронизация истории.
ИИ не встроен в приложение: серверу нужен внешний совместимый ИИ API и секретный ключ. Нельзя помещать секрет в Android/iOS-клиент.
Комнаты пока используют короткий код без пароля/учётных записей. Не используйте для личной или чувствительной переписки. Для публичного запуска нужны авторизация, случайные секреты комнат, лимиты, защита от злоупотреблений, TLS, приватность и аудит безопасности.
Для реальной синхронизации офлайн-истории потребуется зашифрованная серверная очередь или E2E-синхронизация с ключами участников.

## Запуск локально
Нужен Node.js 20+.
```bash
npm install
npm start
```
Открыть `http://localhost:3000`.

## ИИ
Скопируйте `.env.example` в `.env`, задайте `AI_BASE_URL`, `AI_API_KEY`, `AI_MODEL` в окружении сервера и перезапустите его. Для локального запуска можно использовать пакет `dotenv` (добавить зависимость и `import "dotenv/config"`), либо экспортировать переменные в shell.

## Развёртывание
Можно собрать контейнер:
```bash
docker build -t duochat .
docker run --rm -p 3000:3000 --env-file .env duochat
```
Разместите контейнер на хостинге с постоянным HTTPS-доменом и поддержкой WebSocket. Для production задайте `ALLOWED_ORIGIN`.

## Установка на телефоны
После HTTPS-развёртывания:
- Android: открыть сайт в Chrome → меню ⋮ → «Установить приложение» / «Добавить на главный экран».
- iPhone: открыть в Safari → «Поделиться» → «На экран Домой».
Это PWA, не APK/IPA. Нативные проекты Capacitor можно добавить после проверки PWA. Для APK потребуется Android SDK/Gradle; для IPA — Xcode и подпись Apple.


## Быстрый деплой на Render (нужен аккаунт пользователя)
1. Создайте приватный репозиторий GitHub и загрузите в него файлы проекта.
2. В Render выберите New → Blueprint и подключите этот репозиторий.
3. Render прочитает `render.yaml`; подтвердите создание Web Service.
4. Для ИИ задайте секретные переменные `AI_BASE_URL`, `AI_API_KEY`, `AI_MODEL` в настройках сервиса. Не отправляйте API-ключ в чат.
5. После деплоя откройте выданный HTTPS URL на Android/iPhone и добавьте DuoChat на главный экран.

Важно: бесплатные тарифы хостинга могут засыпать/ограничивать ресурсы. Для постоянного чата лучше тариф с постоянно работающим сервисом. Перед приглашением друга протестируйте комнату на двух устройствах.
