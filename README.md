# DuoChat v0.4

Общий чат для небольшой группы: сообщения и ответы ИИ сохраняются в PostgreSQL и загружаются при повторном входе в комнату.

## Что нового в v0.4
- История хранится на сервере в PostgreSQL, а не только в браузере.
- При входе в комнату загружаются последние 2 000 сообщений.
- Новые сообщения пользователей и ИИ записываются в базу до отправки другим участникам.
- Локальная копия в IndexedDB остаётся для быстрого отображения.

## Переменные окружения
- `AI_BASE_URL=https://api.groq.com/openai/v1`
- `AI_API_KEY` — секретный ключ Groq (только в Render Environment).
- `AI_MODEL=openai/gpt-oss-20b`
- `DATABASE_URL` — строка подключения PostgreSQL (Neon или другой PostgreSQL с TLS).

Без `DATABASE_URL` сервер v0.4 не запускается: постоянная история требует базу данных.

## Настройка PostgreSQL через Neon (есть бесплатный тариф, условия могут меняться)
1. Создайте проект PostgreSQL в Neon: https://neon.tech/.
2. Откройте Dashboard проекта и найдите кнопку Connect.
3. Выберите Node.js или обычную строку подключения и скопируйте connection string. В ней обычно есть `postgresql://` и параметр `sslmode=require`.
4. В Render откройте DuoChat → Environment → Add Environment Variable.
5. В поле KEY укажите `DATABASE_URL`, в VALUE вставьте строку подключения Neon.
6. Сохраните переменную кнопкой Save, rebuild, and deploy.
7. После успешного запуска откройте `https://ВАШ-ДОМЕН/health`. В JSON должно быть `"history":"persistent"`.

Не отправляйте строку `DATABASE_URL` никому и не вставляйте её в клиентский код. Она даёт доступ к базе данных.

## Развёртывание обновления
Проект рассчитан на Node.js 20+ и запускается командой `npm start`. Render должен собирать зависимости из `package.json`; новая зависимость `pg` устанавливается автоматически при следующем deploy.

## Важные ограничения
- Комнаты доступны по коду; полноценной авторизации и сквозного шифрования пока нет. Не используйте для секретных или чувствительных переписок.
- История ограничена последними 2 000 сообщениями на комнату.
- Если бесплатный тариф базы данных меняет лимиты или засыпает, доступность может зависеть от провайдера.
- API-ключ Groq хранится только на сервере.
